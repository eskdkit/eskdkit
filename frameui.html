Рамка и основная надпись для чертежа

Изображение или страница PDF помещается на лист с рамкой, дополнительными графами и основной надписью по ГОСТ Р 2.104 (форма 1). Прототип, версия .

Файл обрабатывается в вашем браузере и никуда не отправляется. Страница работает без интернета.

4Удостоверяющий лист

Хэш-код считается по ГОСТ Р 34.11-2012 (256 бит) прямо в браузере. Чертёж с рамкой попадает в УЛ сам; можно добавить и другие файлы комплекта — любые форматы.

Хэш-код относится к PDF в том виде, в каком он сейчас собран. Поменяли реквизиты — скачайте заново и чертёж, и УЛ. При тех же реквизитах файл получается побайтно тем же.

Основная надпись — ГОСТ Р 2.104-2023, форма 1 (для графических документов), с дополнительными графами 19–26. Форматы — ГОСТ 2.301. Изображение вписывается в поле листа без искажения пропорций; масштаб в основной надписи укажите сами — инструмент его не вычисляет. Графы 27–30 для государственного заказа не выводятся. Для электронных документов: при подписании ЭП в графе «Подп.» ставится «ЭП» (ГОСТ Р 2.104-2023, приложение Г); при подписании через удостоверяющий лист — отметка «Подписано с использованием УЛ», а сам УЛ (форма 1 по ГОСТ Р 2.051-2023, приложение А) с хэш-кодом по ГОСТ Р 34.11-2012 выдаётся отдельным PDF. Размеры граф УЛ стандарт оставляет на усмотрение организации. Шрифт DejaVu Sans Condensed (свободная лицензия). Перед выпуском документа проверьте результат.
