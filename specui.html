Таблица обрабатывается в вашем браузере и никуда не отправляется. Страница работает без интернета.

Как заполнять таблицу
РазделДостаточно указать в первой строке группы, ниже можно оставлять пустым. Можно вместо этого вставить строку с одним названием раздела.
ФорматА4, А3… Для деталей без чертежа — БЧ, для документа на листах разных форматов — *).
Поз.Можно не заполнять: номера проставятся сами.
Обозначение, НаименованиеХотя бы одно из двух обязательно.
Кол.Обязательно для всех разделов, кроме «Документация».
ПримечаниеПо необходимости.

Названия колонок можно писать по-своему («Позиция», «Кол-во», «Обозн.») — они распознаются по смыслу. Читается первый лист книги.
