Какие спецификации подойдут

PDF с текстовым слоем по форме ГОСТ Р 2.106 (одна графа «Кол.») или Excel по шаблону со страницы «Спецификация». Для Excel обозначение берётся из имени файла — его можно поправить в таблице. Покупные изделия берутся из раздела «Прочие изделия», материалы — из раздела «Материалы». Количество сборочных единиц перемножается по составу: если плата входит в изделие дважды, её покупные изделия учитываются дважды. Групповые спецификации в PDF (графы «Кол. на исполнение» по ГОСТ 2.113) разбираются по исполнениям: можно составить групповую ВП сразу на все исполнения или ВП на одно исполнение. Строки вида «-03» под обозначением понимаются как исполнение предыдущего обозначения.

Нормы не загружены.

Как заполнять нормы

Одна строка — один материал детали: обозначение детали, материал (марка и документ, например «Лист Б-ПН-1,5 ГОСТ 19903-2015»), норма на одну деталь и единица измерения. Если у детали несколько материалов, следующие строки можно оставить без обозначения. Исполнения (-01, -02) — отдельными строками: норма берётся только при точном совпадении обозначения. Количество деталей на изделие считается по составу, как и для покупных; материалы одной марки из разных деталей складываются.

Замечания

Предпросмотр ведомости появится здесь.

Ведомость покупных изделий — ГОСТ Р 2.106-2019 (п. 4.5, формы 5 и 5а, лист А3), основная надпись — ГОСТ Р 2.104-2023 (формы 2 и 2а). Разделы ведомости составляются по функциональному назначению изделий по первому слову наименования; документ на поставку (ТУ, ГОСТ) отделяется от наименования автоматически. Графы «Код продукции», «Поставщик» и «на регулир.» оставляются пустыми для заполнения. Таблица материалов — справочная сводка по разделам «Материалы» с учётом количества сборочных единиц, это не форма ЕСКД. Для групповой спецификации ВП составляется с графами «Кол. на исполнение» (ГОСТ 2.113): по строке на каждое «куда входит» с количеством на каждое исполнение изделия; дробное количество («1/16») сохраняется дробью. Перед выпуском документа проверьте результат.
